# Colors on the map

Each band shows its color to every player.

- With the **Dynamic Token Ring** on, the ring of each member takes the band's color.
- Without it, the module draws a circle around each member.

When a creature leaves the band or the combat ends, the original ring color comes back.

## Choosing colors

Pick a color for each band in the [Groups and bands window](setup.md#what-you-can-change). New bands get colors that no other band in the combat is using. You can change a band's color at any time from the [Existing bands](existing.md) tab.

[Automatic groups](setup.md#automatic-groups) start without a color.
