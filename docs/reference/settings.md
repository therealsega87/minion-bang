# Settings

Open **Configure Settings → Minion!**.

| Setting | Scope | Default | What it does |
|---|---|---|---|
| **Preselect the proposed minions** | world | on | The [overkill dialog](../table/overkill.md#the-overkill-dialog) opens with the nearest minions checked. When off, nothing is checked and the player picks the minions. The limit on how many can be checked stays. |
| **Shared turns and bands** | world | off | Turns on [automatic groups](../bands/setup.md#automatic-groups), the [Groups and bands window](../bands/setup.md#the-groups-and-bands-window), [shared turns](../bands/turns.md) and [band colors](../bands/colors.md). Not compatible with Squad Combat Initiative. |
| **Initiative of the groups** | world | one roll per group (the captain's) | How a group's initiative is decided: the captain's roll, or the average, highest, lowest or median of all the members' rolls. Applies only when shared turns and bands is on. Each band can override it. See [Initiative and captains](../bands/initiative.md). |
| **Maximum band size** | world | the default table | **Edit the table** opens the [band size table](band-size.md). |
| **Enable Debug** | per user | off | Writes detailed logs in the browser console for every damage event on a minion. Turn it on when you [report a bug](../help/bug-report.md). |
| **Run Diagnostics** | | | Runs a self-test of the rules engine and lets you save a report. See [Reporting a bug](../help/bug-report.md). |

## Language

The interface is in English and Italian. Foundry uses the language each user has chosen.
