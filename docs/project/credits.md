## Credits

Minion! is made by therealsega87.

*Flee, Mortals!* is published by MCDM Productions. This module contains no content from the book: it automates the rules and works with the minions you create or import yourself. You need the book for the rules themselves.

Minion! builds on [Midi-QOL](https://foundryvtt.com/packages/midi-qol) and [socketlib](https://foundryvtt.com/packages/socketlib), and on the D&D 5e system for Foundry VTT.
