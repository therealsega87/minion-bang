## Credits

Minion! is made by therealsega87.

*Flee, Mortals!* is published by MCDM Productions. This module contains no content from the book. It automates the rules and works with minions you create or import yourself, so you still need the book for the rules.

Minion! builds on [Midi-QOL](https://foundryvtt.com/packages/midi-qol), [socketlib](https://foundryvtt.com/packages/socketlib) and the D&D 5e system for Foundry VTT.
