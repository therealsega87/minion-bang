# Reporting a bug

A good report gets a fix faster. It takes five minutes.

1. Open **Configure Settings → Minion!** and turn on **Enable Debug**.
2. Make the problem happen again.
3. Click **Run Diagnostics**. It runs a self-test of the rules engine and shows how many checks passed.
4. Click **Save Report**. The file has your module versions, the settings and the recent activity.
5. Open an [issue on GitHub](https://github.com/therealsega87/minion-bang/issues). Attach the report and write a few lines: what you did, what you expected and what happened.

Also useful: the line with the Minion! version from the browser console (++f12++), and whether you reloaded with ++ctrl+f5++ after the last update.

If you prefer, write on [Discord](https://discord.com/users/688483231531532323): **therealsega87**.

Turn **Enable Debug** off again when you're done. It writes a lot to the console.
