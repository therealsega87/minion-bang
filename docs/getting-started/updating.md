# Updating

Foundry lists Minion! among the modules with an update. Install it from there.

After every update, **everyone at the table** reloads the page with ++ctrl+f5++.

!!! warning "Use Ctrl+F5, not F5"
    A normal reload can keep the old files in the browser cache. The windows then behave like the previous version, and bugs that were already fixed seem to come back.

## Check which version is running

When the world loads, Minion! writes its version in the browser console (++f12++). If a player reports a problem, ask them for that line first. A player on an old version explains many odd reports.

## Statistics modules

If you use Combat Stats and you change its mode, reload with ++f5++ as Combat Stats asks. Combat Stats applies a new mode only after a reload. See [Combat Stats](../reference/combat-stats.md).

## Before a session

After you update Minion!, Midi-QOL, dnd5e or Foundry itself, run one fight with a few minions before the session. Check the plain hit, an overkill and, if you use them, the bands. Minion! is tested against the versions listed in [Compatibility](../reference/compatibility.md), and a newer version of those modules can change something Minion! relies on.
