# Updating

When a new version is out, Foundry lists Minion! among the modules with an update. Update it from there.

After every update, **everyone at the table** reloads the page with ++ctrl+f5++.

!!! warning "Use Ctrl+F5, not F5"
    A normal reload can keep the old files in the browser cache. The windows then behave like the previous version, and bugs that were already fixed seem to come back.

## Check which version is running

When the world loads, Minion! writes its version in the browser console (++f12++). If a player reports something odd, ask for that line first. A browser still running the old version is behind many strange reports.

## Combat Stats

If you use Combat Stats and change its mode, reload with ++f5++ as Combat Stats asks. Combat Stats only switches mode after a reload. See [Combat Stats](../reference/combat-stats.md).

## Before a session

After you update Minion!, Midi-QOL, dnd5e or Foundry, run a short fight with a few minions before the session. Try a plain hit, an overkill and, if you use them, the bands. Minion! is tested with the versions in [Compatibility](../reference/compatibility.md), and a new version of any of them can change something Minion! relies on.
